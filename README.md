# NEXUS Market

A **Flipkart/Amazon‑style** e‑commerce clone built with React, Vite, Tailwind CSS, and the Stitch design system.

## Features
- Product catalog with multiple categories (phones, laptops, cameras, etc.)
- Login / registration pages
- Shopping cart, wishlist, checkout flow
- Responsive UI following the Stitch design tokens
- Clean, searchable codebase following the project coding standards

## Getting Started
```bash
# install dependencies
npm install

# run development server
npm run dev
```

Visit `http://localhost:5173` to explore the app.
