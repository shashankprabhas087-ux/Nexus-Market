---
description: Build one page from its Stitch design
---
1. Read `.agent/rules/05-pages-and-routes.md` and find the Stitch folder for the requested page.
2. View `screen.png` and read `code.html` in that folder.
3. List the components needed; reuse existing ones in `src/components` before creating new ones.
4. Create missing components, then the page, then wire the route.
5. Run the dev server, check 1440px and 390px widths against `screen.png`.
6. Fix mismatches, run `npm run build`, and summarize what changed.
